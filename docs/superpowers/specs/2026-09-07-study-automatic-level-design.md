## 1. 성격 — 읽는 글이 아니라 들고 나가는 매뉴얼

기존 여덟 편은 "무엇을 왜 재는가"를 설명하는 글이었습니다. 이번 것은 **실습 중에 펼쳐 놓고 따라 하는 절차서**입니다. 그래서:

- 절차는 번호 단계로, 한 단계가 한 동작이 되게 씁니다("정준나사 두 개를 동시에 반대로 돌린다").
- 현장에서 쓰는 수치(시준거리 상한, 전후시 거리차, 허용 폐합)는 표 하나에 모아 눈으로 찾게 합니다.
- 야장 서식을 그대로 싣고, 채워진 예제와 빈 서식을 함께 둡니다.
- 실습 전에 볼 영상 세 개를 앞쪽에 둡니다.

## 2. 단위

**US 관용단위가 기본**입니다. 표척 읽음·표고는 ft, 0.01 ft 단위. 시준거리는 ft, 루프 길이는 마일(허용 폐합식이 마일 기준). SI 는 필요한 곳에만 괄호로 병기하지 않습니다 — 이 매뉴얼은 ft 로만 씁니다(사이트의 다른 글과 같은 관용).

## 4. 규격표 (`tbl-specs`) — Caltrans Table 8-2, 3급, 보상기 레벨 단선 관측

| 항목 | 값 |
|---|---|
| 최대 시준거리 | 300 ft |
| 전시·후시 거리차(설치당) | 33 ft 이내 |
| 전시·후시 거리차(루프 누적) | 33 ft 이내 |
| 시준선 지면 여유 | 1.6 ft 이상 |
| 루프 최대 폐합오차 | 0.06 ft × √E (E = 루프 길이, 마일) |
| 구간 최대 폐합오차 | 0.06 ft × √D (D = 구간 편도, 마일) |
| 2-peg 점검 | 매일, 0.007 ft / 200 ft 초과면 조정 |

각주: 2급은 0.003 ft / 200 ft. 더운 날 포장 위에서는 시준거리를 1/3 이상 줄인다(출처 B).

## 5. 예제 (`tbl-fieldbook`, `tbl-peg`) — 조사 노트에서 검산 완료, "example numbers"

폐합 루프 BM-1(가정 100.00 ft) → TP1 → TP2 → TP3 → BM-1, 시준거리 약 150 ft × 8 = 1,200 ft.

| 설치 | BS | HI | FS | 표고 |
|---|---|---|---|---|
| BM-1 | 4.32 | 104.32 | | 100.00 |
| TP1 | 5.18 | 102.75 | 6.75 | 97.57 |
| TP2 | 2.86 | 102.57 | 3.04 | 99.71 |
| TP3 | 8.11 | 103.26 | 7.42 | 95.15 |
| BM-1 | | | 3.28 | 99.98 |

ΣBS 20.47 − ΣFS 20.49 = −0.02 = 99.98 − 100.00 ✓ / 폐합 −0.02 ft, 1,200 ft = 0.227 mile → 허용 0.06√0.227 = 0.029 ft → 합격 / 보정 +0.005 ft/설치 누적 → 97.58, 99.72, 95.17, 100.00.

2-peg: ① a₁ 5.284, b₁ 4.716 → ΔH 0.568 / ② a₂ 4.958, b₂ 4.386 → 겉보기 0.572 / 오차 **0.004 ft/200 ft**(3급 합격, 2급 불합격) / B 의 옳은 읽음 4.390 ft.
