# MixLab — Concrete Mix Design Challenge · 설계 스펙

- 날짜: 2026-08-28
- 상태: 사용자 승인된 설계 (브레인스토밍 완료)
- 대상: 콘크리트 수업(ACI 211.1, US 관용단위)을 듣는 학생용 웹 게임

## 1. 목적

학생이 ACI 211.1 배합설계 절차를 **표를 직접 읽으며** 단계별로 수행하고,
그 결과를 가상 슬럼프 시험(ASTM C143)과 압축강도 시험(ASTM C39)으로 확인하는
미션 기반 학습 게임. 물이 많으면 슬럼프 콘이 완전히 붕괴하고, 물이 적으면
슬럼프가 거의 없는 등 **배합의 물리적 결과를 눈으로 확인**하는 것이 핵심 학습 장치.

## 2. 확정된 요구사항 (Q&A 결정 사항)

| 항목 | 결정 |
|---|---|
| 단위계 | US 관용단위 (lb/yd³, in., psi) |
| 설계 절차 | ACI 211.1 표준 7단계, 비공기연행 + 공기연행 모두 지원 |
| 검증 방식 | 단계별 정답 검증 **없음** — 자유 입력 후 시험 결과로 확인 |
| 게임 구조 | 프로젝트 미션 + 점수/등급 |
| 기술 형태 | 바닐라 JS + Canvas 2D, 프레임워크·빌드 도구 없음 |
| 배포 | 단일 HTML(dist/index.html)로 인라인 빌드 → Netlify 배포 |
| 디자인 | 라이트 SaaS 위저드 (Mobbin: Zillow/Remote/ElevenLabs 레퍼런스) |
| UI 언어 | 영어 |
| 애니메이션 | Canvas 절차적 애니메이션 (물리 엔진 없음) |

## 3. 게임 흐름 — 6개 장면 (state machine)

`HOME → DESIGN(step1..7 + summary) → MIX → SLUMP → COMPRESSION → RESULTS`

### 3.1 HOME — 미션 선택
미션 카드 5종. 각 카드: 구조물 종류, 요구 f'c, 요구 슬럼프 범위, 노출 조건
(공기연행 필요 여부), 사용 가능 굵은골재 최대치수(NMAS).

| # | 미션 | f'c (psi) | 슬럼프 (in.) | 공기연행 | 비고 |
|---|---|---|---|---|---|
| 1 | Residential Slab | 3,000 | 3–4 | 불필요 | 입문용 |
| 2 | Bridge Deck | 4,500 | 3–4 | 필수 (~6%) | 동결융해 노출 |
| 3 | High-rise Column | 6,000 | 4–5 | 불필요 | 저 w/c 도전 |
| 4 | Sidewalk Pavement | 4,000 | 1–3 | 필수 (~6%) | 낮은 슬럼프 |
| 5 | Basement Wall | 3,500 | 3–6 | 불필요 | 관대한 범위 |

### 3.2 DESIGN — ACI 7단계 위저드
각 단계 = 좌측 입력 카드 + 우측 스티키 참고 패널(해당 ACI 표 원문 스타일).
표에는 힌트·자동입력 없음. 행 hover 하이라이트만 제공.

1. **Slump 선택** — 참고표: 공사 종류별 권장 슬럼프 (ACI Table 6.3.1 기반)
2. **NMAS 선택** — 미션이 허용하는 치수 중 선택 (3/8", 1/2", 3/4", 1", 1.5")
3. **단위수량·공기량** — 참고표: 슬럼프×NMAS별 소요 수량 lb/yd³,
   비공기연행(+갇힌 공기량)/공기연행(노출등급별 목표 공기량) (Table 6.3.3 기반).
   입력: water (lb/yd³), target air (%)
4. **w/cm 선택** — 참고표: 28일 압축강도 vs w/c (비공기연행/공기연행 열)
   (Table 6.3.4(a) 기반). 헬퍼 노트: "assume f'cr = f'c + 1,200 psi".
   입력: w/c (비율)
5. **시멘트량** — 계산 안내(cement = water ÷ w/c)만 제공, 학생이 직접 계산해 입력 (lb/yd³)
6. **굵은골재량** — 참고표: NMAS×잔골재 FM별 건조봉다짐 굵은골재 용적비
   (Table 6.3.6 기반). 재료 데이터: DRUW 100 lb/ft³, sand FM 2.70.
   입력: CA weight (lb/yd³) = 용적비 × 27 ft³ × DRUW
7. **잔골재량 (중량법)** — 참고표: NMAS별 굳지 않은 콘크리트 추정 단위중량
   (Table 6.3.7.1 기반). FA = 추정 총중량 − water − cement − CA. 입력: FA (lb/yd³)

- 재료 물성은 "Materials Lab Report" 카드로 상시 제공:
  시멘트 SG 3.15, CA SG 2.65 / DRUW 100 lb/ft³, FA SG 2.64 / FM 2.70
- 요약 화면: 배합표 전체 + "Batch & Mix" 버튼
- 입력 클램프: water 100–500, cement 200–1200, CA 0–2500, FA 0–2500,
  air 0–10 %, w/c 0.25–1.00. NaN → 이전 값 복원

### 3.3 MIX — 믹싱 장면
드럼 믹서 Canvas 애니메이션(~4초, 스킵 가능). 재료 순차 투입(시멘트·물·골재)
→ 드럼 회전 → 반죽 질감/색이 배합 반영(질퍽함·퍼석함).

### 3.4 SLUMP — 슬럼프 시험 장면
콘 3층 채움·다짐(자동) → 콘 서서히 인발 → 엔진이 계산한 슬럼프값에 따라 4가지 거동:

| 거동 | 조건(개략) | 시각 표현 |
|---|---|---|
| Zero slump | slump < 0.5 in | 뻣뻣한 원뿔 유지, 표면 거침 |
| True slump | 정상 범위 | 매끄럽게 주저앉음, 둥근 상부 |
| Shear slump | 거친 배합(모르타르 부족) 경계 | 반쪽이 미끄러져 떨어짐 |
| Collapse | slump > ~8 in / 과다 수량 | 웅덩이처럼 퍼짐 + 블리딩 수막 링 |

측정: 자 + 뒤집은 콘 그래픽, 측정값 = 계산값 ± 0.25 in 노이즈.

### 3.5 COMPRESSION — 압축강도 시험 장면
공시체 3본(6×12 in.) 제작 → 양생 타임랩스(28일) → UTM 재하:
하중(lbf)·응력(psi) 실시간 카운터 + 응력-변형률 곡선 실시간 드로잉 →
피크에서 파괴 애니메이션(원추형/기둥형 — 품질에 따라) →
3본 결과(±~5% 산포) → 평균 = 측정 f'c.

### 3.6 RESULTS — 결과 리포트
채점(총 100점):

| 항목 | 배점 | 기준 |
|---|---|---|
| 슬럼프 적합 | 40 | 요구 범위 내 만점, 벗어난 거리 비례 감점 |
| 강도 달성 | 40 | 측정 평균 ≥ f'c 만점, 미달 비례 감점 |
| 공기량 | 10 | AE 미션: 목표 ±1.5%p 내 만점, 이탈 비례 감점 / 비AE 미션: air ≤ 3% 만점 |
| 수율(Yield) | 10 | 절대용적 합 ≈ 27 ft³/yd³ (오차 비례 감점) |

등급 A–F + 별점, 실패 원인 해설(예: "Too much water — the cone collapsed"),
재도전/새 미션 버튼. localStorage에 미션별 최고 기록 저장.

## 4. 시뮬레이션 엔진 (순수 함수)

엔진은 **학생의 실제 투입량**(water, cement, CA, FA, air%)만으로 판정.
표를 맞게 읽었는지는 보지 않음 — 물리량 기준.

- **유효 w/c** = water ÷ cement (4단계에서 입력한 w/c는 설계 의도일 뿐, 판정은 실투입 기준)
- **슬럼프 예측**: ACI 수량 표를 역산 — 선택 NMAS·공기연행 여부에서
  수량→슬럼프 단조 곡선으로 계산. 극단값: 과다 → collapse, 과소 → zero.
  굵은골재 과다/모르타르 용적 부족 → shear slump + segregation 플래그.
  slump > 7 in → segregation 플래그.
- **28일 강도**: Abrams형 곡선 `f'c = A / B^(w/c)` 를 ACI Table 6.3.4(a)
  기준점(비공기연행: 2000→0.82 … 6000→0.41 / 공기연행 열 별도)에 맞춰 캘리브레이션.
  보정: 공기량 1%p 초과당 약 −5%, segregation 감점, 페이스트/모르타르 부족
  (honeycomb) 감점. 공시체별 산포 ~N(1, 0.04).
- **수율**: V = C/(3.15·62.4) + W/62.4 + CA/(2.65·62.4) + FA/(2.64·62.4)
  + 27·(air%/100) [ft³] → 27 ft³ 대비 오차.

## 5. 디자인 시스템 (Mobbin 라이트 SaaS)

- 레이아웃: max-width ~1,100px 중앙 정렬. 상단 앱바(로고 MixLab + 미션 칩 + 점수).
  Zillow식 수평 스텝퍼(진행선 + 체크 도트). 본문 2컬럼(좌 입력 카드 / 우 스티키 표 패널).
  하단 Back / Next(프라이머리 블루).
- 색: 흰 배경 #ffffff, 서피스 #f7f8fa, 프라이머리 블루 계열, 슬레이트 텍스트,
  성공 그린 / 경고 앰버 / 실패 레드.
- 타이포: Inter (Google Fonts), 표 숫자는 tabular-nums.
- 표 스타일: 줄무늬 행, hover 하이라이트, 클릭 자동입력 없음.
- 시험 장면: 라이트 프레임 유지, Canvas 무대만 은은한 랩 그라데이션.
- 반응형: 태블릿 이상 2컬럼, 모바일은 스택 + 참고표 아코디언.

## 6. 기술 구조

```
D:\Projects\Test\
├── index.html        # UI·장면·Canvas 렌더러 (dev에서 engine.js를 <script src>로 로드)
├── engine.js         # 순수 계산 함수 (슬럼프/강도/수율/채점/분류) — UMD풍, node에서도 로드 가능
├── engine.test.mjs   # node --test 단위테스트
├── build.mjs         # engine.js를 인라인해 dist/index.html 단일 파일 생성
└── dist/index.html   # 배포 산출물 (완전 단일 파일)
```

- 프레임워크 없음, 외부 의존성은 Google Fonts(Inter)만.
- 전역 상태: 단일 `game` 객체 + 장면 state machine.
- Canvas 미지원 시 텍스트 결과 폴백.
- 새로고침 시 홈으로 (진행 상태 비저장), localStorage는 최고 기록만.

## 7. 테스트·검증

1. **엔진 단위테스트** (`node --test engine.test.mjs`):
   ACI 표 기준점 재현(±허용오차), 슬럼프 역산 단조성, 공기 보정,
   수율 계산, 채점 경계값, 거동 분류 임계값.
2. **플레이 검증 3종** (브라우저에서 실제 플레이 + 화면 캡처 대조):
   - ⓐ 교과서 정답 배합(미션1) → true slump·범위 내·강도 합격
   - ⓑ 동일 배합에 물 +100 lb → collapse·강도 미달
   - ⓒ 물 과소(−100 lb) → zero slump
3. **배포 검증**: dist/index.html 단일 파일이 file:// 로도, Netlify URL로도 동작.
